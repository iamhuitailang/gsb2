语音接收缓冲（Jitter Buffer）演示 —— 晚到 / 乱序 / 缺块 / 重复

模型与使用说明（点击展开）
  • 声源为程序生成的旋律（小星星，16kHz 单声道），切成 64 块 × 100ms，块带序号，媒体时间 = 序号 × 100ms。
  • 到达表每行 序号 到达时刻ms；同一块多行 = 重复收到；没有行 = 丢失。可用预设+种子生成，也可手工编辑后点「应用到达表」。
  • 播放期限 = 块媒体时间 + 缓冲等待 offset。到期限未收到的块不回头补：该位置补空（静音或重复上一块），晚到的块直接丢弃。
  • 固定等待：offset 恒定。自适应：按最近到达延迟的 95 分位 + 余量调整 offset；需要大幅拉长时插入一个「主动等待」拍（可听到的停顿），小幅则平滑漂移。
  • 播放 / 走一步 / 跑完三种入口共用同一个确定性 step 函数，同输入同配置结果必然一致；「校验一致性」会把当前结果与从头跑一遍逐样本对比。
  • 播放中改参数立即生效并记录在时间图和事件日志里（橙色虚线），可分清哪一段用的是哪组参数。
  • 导出 WAV 就是界面里听到的那条 PCM；导出 JSON 含每块决定、打断次数与延迟统计。
