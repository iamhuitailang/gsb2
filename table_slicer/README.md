# 表格切格检查工具（本地）

只把纸上扫描的小表样**切成每格的图片**，不做文字识别。针对扫描件常见的
合并格、浅框线、印章压线、框线缺口和轻微旋转，提供"自动检测 + 人工核对 +
导出"的本地工作流。所有数据留在本机，服务只监听 `127.0.0.1`。

## 安装与启动

```bash
pip install -r requirements.txt
python3 run.py [项目目录] [--port 8765] [--no-browser]
```

不指定项目目录时默认 `./slicer_project`。浏览器打开 `http://127.0.0.1:8765/`。

> 安全说明：项目数据目录（原图、拉正图、导出）与代码目录分离，外来图片只通过
> 界面/接口放进项目目录，不要放进代码目录，以免同名模块干扰导入。

## 工作流

1. **取图**：点「生成样图」造一张带全部缺陷的合成表（同时存真值），或
   「打开本地图片」选扫描件。
2. **自动检测**：拉正 → 找外框和行列分隔 → 逐边段评估 → 建网格。
   找不到表格的图标记为**待处理**，不影响其他图。
3. **人工核对**：在拉正预览上切换边段、增删分隔、确认/取消合并；
   左侧「低可信项」逐条列出判不准的边，点击即可采纳人工判定。
4. **导出**：单图或批量导出每格小图 + `manifest.json`（位置、行列跨度、编号）。
5. **自检**：合成图可对真值核对格数、合并关系和裁切像素偏差。

## 六条需求的落实

### 1. 合成缺陷图 / 打开本地图片
`slicer/synth.py` 可生成含合并格、浅框线（低对比灰线）、红色印章压线、
框线短缺口、轻微旋转（含扫描噪声）的表样，并写出 `*.truth.json`。
界面「打开本地图片」支持任意本地图片（彩色/灰度均可）。

### 2. 找外框和行列分隔，短缺口可补，但不臆造合并格的边
- 横/竖线分别形态学开运算提取，投影峰聚类定位候选线，再取外框。
- 每条线**按相邻正交线之间的区段**单独评估，而不是整条一刀切。
- 边段三态：
  - `present` 连续框线（含浅线、桥接的短缺口，桥接会标 `bridged`）；
  - `absent` 基本无墨迹，按合并格无边处理，**绝不自动补成实线**；
  - `uncertain` 有零星墨迹或印章大面积遮挡、判不准，进**低可信清单**交人工。
- 判定同时看支持率、**最长连续墨迹游程占比**和最长缺口，避免把合并格
  上下方共线的两段边框误连成一条穿过合并区的线。

### 3. 原图与拉正预览联动、可增删分隔/确认合并，相邻格正确更新
- `geometry.py` 维护拉正图↔原图的仿射逆变换，悬停/点击在两图间联动高亮。
- 拉正预览上可：切换边段实线/无边、在任意位置加横/竖分隔、删除非外框线、
  框选确认矩形合并范围、取消合并。
- 每次编辑后网格重新做洪水填充，相邻格的合并关系与编号即时重算。

### 4. 按空间位置编号，保留行列跨度，空白/缺图不前移编号
- 每个逻辑槽位固定编号 `R{行}C{列}`；合并格取左上角锚点编号并记录
  `span=[行跨度,列跨度]`，被覆盖槽位标 `covered:R..C..`。
- 空白格照常导出并打 `blank` 标记；异常矩形记 `missing` 但不跳过序号。
- 导出顺序号 `seq` 仅用于文件命名，与空间编号解耦。

### 5. 导出格图/位置/行列说明，并对已知表自检
- `exports/<图名>/images/NNN_RrCc.png` 为每格小图，`manifest.json` 记录
  每格的锚点、跨度、像素矩形、尺寸、可信度、备注。
- 合成图的「自检」对照真值校验：行列数、格子数、合并关系、编号一一对应、
  裁切四角像素偏差（默认容差 6px）。

### 6. 找不出的样图标待处理，其他图照常导出
- 检测失败统一转 `pending`（含原因），不抛栈、不中断。
- 「批量导出」跳过待处理图并在结果中说明，其余图正常保存。

## 测试

```bash
python3 -m unittest tests.test_units tests.test_e2e -v   # 20 个测试
python3 tests/smoke_core.py                              # 端到端冒烟 + 自检报告
```

覆盖：合并洪水填充、uncertain 默认封闭、增删线的索引维护、编号稳定性、
几何往返、多旋转角多种子端到端、合并内边不被臆造、外框缺口处理、
印章压线的保守判定、导出清单完整性、待处理隔离。

## 主要可调参数（slicer/detection.py、exporter.py）

| 参数 | 含义 | 默认 |
|---|---|---|
| 支持率 present 阈值 | 高于此且游程够长才判实线 | 0.72 |
| 游程占比阈值 | 最长连续墨迹/有效长度，防共线误连 | 0.55 |
| 缺口桥接支持率/最大缺口 | 两端有墨时允许桥接的区间 | 0.42 / 图宽 1/45 |
| 无墨迹 absent 阈值 | 低于此按合并无边 | 0.12 |
| `BLANK_INK_RATIO` | 格内墨迹占比低于此判空白 | 0.006 |
| `CROP_MARGIN` | 裁切向内收的像素，避免带邻格线 | 3 |
