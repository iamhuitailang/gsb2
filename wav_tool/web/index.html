比较总采样帧数（每声道样本数）和解码后的实际样本；差异会合并成连续区间，报告起始/结束采样帧与时间。

命令行与自动化验收

python3 wav_tool.py serve
python3 wav_tool.py demo --case all --out demo_output
python3 wav_tool.py split input.wav --interval 1 --out split_out
python3 wav_tool.py restore split_out/manifest.json -o restored.wav --compare-original input.wav
python3 -m unittest discover -s tests -v

CLI 可用 --map 2=/path/to/wrong.wav 模拟调换；退出码 0 表示样本完全一致，2 表示分段校验未通过，3 表示比较发现差异。
