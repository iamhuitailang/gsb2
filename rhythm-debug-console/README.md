# 节奏谱面判定调试台

一个零依赖、零构建的本地调试台，用来弄清**变速段换算**和**长按结尾计分**。
所有声音（节拍器、音符提示音、判定音）与时间轴图形都由程序实时生成，没有任何外部素材。

直接双击 `index.html` 即可在浏览器打开（`file://` 下完整可用，无需服务器）。

## 判定规则（窗口边界一致）

判定窗口三参数（毫秒，**边界一律按“含”处理**，统一用毫秒级整数比较避免浮点误差）：

| 参数 | 含义 |
|---|---|
| `perfectMs` | 完美窗，`|dt| ≤ perfectMs` 判完美 |
| `lateMs` | 总判定窗，`perfectMs < |dt| ≤ lateMs` 判良好，超出即漏拍 |
| `releaseMs` | 长按尾部容差，在 `endTime - releaseMs` 之后松开算完成，否则提前松开 |

`dt = 输入时刻 − 音符时刻`，负=早、正=晚、0=准。

### 计分

| 事件 | 基础分 |
|---|---|
| 单点 完美 / 良好 / 漏拍 | 1000 / 600 / 0 |
| 长按头部 完美 / 良好 | 500 / 300 |
| 长按尾部 完成 | 500 |
| 提前松开 / 漏拍 | 0 |

每次非断连判定额外加 `min(当前连击, 50) × 10` 的连击奖励；漏拍和提前松开清零连击。

### 关键防重复计数规则

- 每个 `down` 输入**最多匹配一个音符**：在所有窗口覆盖该时刻且尚未处理的音符中，取 `|dt|` 最小者，平局取时间更早的音符。
- 每个音符只接受第一个匹配输入，错过死线（`startTime + lateMs`）即漏拍。
- 单键模型下键未松开时的重复 `down` 记为无效输入，不会触发任何音符。
- 输入事件与漏拍死线/长按自动完成等合成事件统一按时间排序，同一时刻**先处理输入再处理死线**，保证窗口边界（含）始终可判。

### 长按三态

- **按住完成**：头部被按下且在 `endTime - releaseMs` 之后松开 → 完成。
- **提前松开**：在容差窗之前松开 → 提前松开，断连击。
- **一直不松**：到 `endTime` 自动完成（dt=0）。
- 头部就没按下 → 整音漏拍。

## 变速与时间轴

- 变速段 `segments: [{beat, bpm}]` 在指定 beat 处切换 BPM，段内 `beat 时长 = 60/bpm 秒`，分段线性换算。
- 时间轴上行是**拍号刻度**（小节线加重，标小节号），下行是**实际秒数**；变速段背景分段着色并标注 BPM，变速点用虚线标出。
- 音符按实际秒数稳定排序，变速前后相邻音符顺序始终正确；示例 `h1`（beat 6→10）头部在 100 BPM 段、尾部在 160 BPM 段。

## 检查点与确定性回放

判定是纯函数：同一份谱面 + 同一份输入记录，无论回放多少次、从哪个检查点拖回重放，判定、连击、分数都逐值一致（见 `engine.selftest()` 的前缀回放断言）。

- **设检查点**：在当前播放位置打标记（时间轴黄色虚线）。
- **回检查点重放**：从该时刻重新调度同一批输入，连击/分数从该时刻的快照接续。
- 模拟输入由带种子的 PRNG（mulberry32）生成，同 seed 完全可复现。

## 双窗口对照

右侧「双窗口对照」页可分别配置 A/B 两组窗口，对**同一份输入记录**各跑一次判定：

- 逐音符列出两组的头部、尾部判定及**原始偏差 dt（毫秒）**；
- 有分歧的音符整行高亮并在首列标 ⚠，顶部汇总两组总分/最大连击与分歧数量。

## 存档

- 「存档」页写入浏览器 localStorage；支持载入、**载入并一键回放**、删除。
- 顶栏「导出 JSON / 导入 JSON」走文件，格式为 `rhythm-debug-console/v1`，含谱面、输入记录和两组窗口参数。
- `examples/sample-save.json` 即要求的跨变速长按 + 两个相邻单点示例：导入后点回放即可一键走完。

## 手动录制

勾选「录制手动输入」后，回放过程中按空格交替记录 down/up，时间戳取自当前谱面时刻；松开勾选复位按键状态。未回放时没有谱面时间基准，会提示先开始回放。
