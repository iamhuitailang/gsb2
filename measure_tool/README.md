# 黑白零件图轮廓测量小工具

一个**纯本地运行**的扫描零件图测量工具：用图上的横纵标尺建立像素→毫米
标定（标尺可以斜着放、两尺可以不正交），调阈值分割出零件轮廓，
点选零件读取外宽外高、填充/孔面积和多方向投影，并能把两次参数的结果
叠加对比每个孔的去向。所有计算在本机完成，不访问任何网络。

## 适用场景与边界

- 浅色背景、深色零件的黑白扫描图（深底浅图可勾选“反色”）。
- 横、纵两根标尺各点选两个端点并给出真实毫米长度；工具按斜坐标
  仿射基换算，因此**标尺不与图片边平行、两尺不严格垂直也能给数**。
- 可靠读数的前提是零件完整落在两根标尺张成的有效平行四边形内；
  超出部分会在界面和读数里明确告警。断到图片边的区域只能给
  “被截断后的可见尺寸”，工具会强制标注不可靠。

## 快速开始

```bash
cd measure_tool
python3 -m pip install -r requirements.txt   # 首次安装依赖
python3 run_app.py                          # 启动，默认 http://127.0.0.1:8765
```

浏览器打开 `http://127.0.0.1:8765` 即可。想重建程序绘制的演示图：

```bash
python3 run_demo.py
```

## 操作流程（对应左侧四个卡片）

1. **演示数据 / 导入扫描图**：可先加载 A/B/C 三张带已知真值的程序图，
   或直接导入自己的扫描件。
2. **标尺标定**：在图上依次点横尺两端、纵尺两端，填各自毫米长度后
   “应用标定”；演示图可一键标定。黄色虚线框即有效测量区域。
3. **分割阈值**：拖动阈值/小黑点门槛实时预览轮廓。
   绿色=完整外轮廓，红色=孔，黄色=断到图边的区域。
   面积小于“小黑点门槛”的孤立黑块会被过滤，调大门槛可忽略标尺刻度和噪点。
4. **点选零件读数**：点击任一零件，右侧面板给出
   - 外宽、外高（沿横/纵尺方向，**含孔的外轮廓口径**）；
   - 外轮廓面积（含孔）、实际填充面积（**已扣除全部封闭孔**）、
     孔面积合计与每个孔的尺寸；
   - 图轴 0/45/90/135° 与横纵尺方向共 6 个投影尺寸；
   - 有效区内轮廓点占比，超界时红色高亮出界点并给告警。
   读数可标记“待确认/已确认”并附备注。

### 两次结果叠加（孔的去向）

调好一版参数后点“存为快照 A”，再改阈值或标尺、点“与快照对比”。
面板对每个孔给出三种命运之一：

- **仍作为单独的孔**：两版都是封闭背景连通域；
- **被识别成背景（含与外部连通）**：孔与外部背景打通，不再是封闭孔；
- **被识别成零件（孔被填实）**：原孔位置在新版里变成零件像素。

紫色虚线叠加旧轮廓，有歧义的读数可留在“待确认”状态。

### 导出 / 读回 / 描边

- “导出工程 JSON”：保存标定、全部轮廓点、分割参数、毫米读数、
  待确认状态和对比结果，同时在 `output/` 生成一张描边 PNG
  （有效区、外宽/外高测量线、投影线、彩色边界）。
- “读回工程”：载入 JSON 后在当前原图上重绘轮廓与测量，并校验
  图片尺寸是否与工程一致。
- “生成描边图”：浏览器内直接查看当前测量用的线段和边界。

## 演示图与误差验证（需求 6）

三张演示图都以 10 px/mm 的已知比例绘制，真值见
`demo/ground_truth.json`：

| 文件 | 场景 | 能验证什么 |
|---|---|---|
| `demo_a_aligned.png` | 零件正放、标尺平行图边 | 基础尺寸/面积误差，圆盘直径读数误差 < 1% |
| `demo_b_rotated.png` | 零件旋转 25°、标尺整体倾斜 12° | 斜标尺下面积与孔数不变、投影极值仍能找回局部边长 |
| `demo_c_edge.png` | 零件被图边截断、一个孔开口与外部连通 | 贴边区域被强制标不可靠；开口孔不计入封闭孔 |

跑自动化测试（含已知尺寸误差核对）：

```bash
python3 -m pytest tests/ -q
```

关键测试在 `tests/test_demo_accuracy.py`，容许误差取 0.3 mm / 1.5%
（演示图带模糊和噪声，不是理想矢量图）。

## 哪些场景没法可靠给读数

工具会明确告警而非静默给数：

1. 零件轮廓超出标尺有效区域——毫米值是仿射外推，仅供参考；
2. 零件与图片边界相接——外宽/外高/投影只是截断后的可见尺寸；
3. 孔与外部背景连通——它不是封闭孔，不计入孔面积；
4. 两尺 mm/px 差异过大或两尺近乎平行——标定质量面板会提示。

## 代码结构

```
measure_tool/
├── run_app.py              # 本地服务入口
├── run_demo.py             # 重建演示图
├── core/
│   ├── geometry.py         # 斜坐标标定、像素<->毫米、有效区域
│   ├── segmentation.py     # 二值化、轮廓层级、孔/碰边/小黑点
│   ├── measurements.py     # 外宽高、面积、投影、可靠性告警
│   ├── compare.py          # 两次分割的孔命运分类
│   ├── export_project.py   # 工程导出/读回/描边
│   ├── demo_data.py        # 程序绘制演示扫描图与真值
│   └── app.py              # Flask HTTP 接口
├── web/                    # 原生 JS 单页界面（无前端构建）
├── tests/                  # pytest 测试 + 浏览器冒烟脚本
└── demo/ output/           # 演示图与导出产物
```
