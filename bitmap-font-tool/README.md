# 位图字体工具（字形图集与度量生成器）

纯本地网页工具，零依赖、无在线字体库：直接用浏览器打开 `index.html` 即可使用。

## 功能

1. **导入与诊断**
   - 导入字符映射表（JSON `{"A":"A.png"}` 或 CSV `字符,文件名`）与字形 PNG 图片
   - 无映射表时按文件名推断字符：`A.png`→A、`U+4E2D.png`→中、`space.png`→空格
   - 诊断面板列出：缺字（映射表有、图片缺失）、重复映射（一字多映射 / 一图多字）、
     空白字形（完全透明，空格标记为预期），字形表中带来源文件列

2. **度量编辑与排版预览**
   - 每个字形可调：边距、基线、前进宽度；全局可调：字符间距、行高、全局基线、缺字宽度
   - 预览短句按度量贪心换行（空格与中日韩字符为断点，超长单词按字硬拆），
     测量与渲染共用同一套步进函数，换行结果与单字度量严格一致
   - 缺字以红框 `?` 占位显示

3. **图集排布**
   - 架式（shelf）算法自动排布，结果确定；可设图集边缘留白
   - 超出图集尺寸放不下的字形逐个列出（含来源文件）

4. **尺寸比较**
   - 128～4096 各尺寸占用率一览，点击即切换；重新排布只改变图集坐标，
     字符映射与度量（前进宽度等）不变

5. **工程与导出**
   - 保存工程 `.bfproj.json`（内嵌图片与全部设置），导入后可继续修改
   - 导出图集 PNG、度量清单 JSON（BMFont 风格字段）、BMFont `.fnt` 文本

6. **示例素材**
   - `sample/generate_sample.py` 用本机系统字体（Helvetica / PingFang）渲染示例字形，
     包含标点、空格、宽窄差异字符（`i`/`l` 与 `W`/`M`/中文）

## 使用

```bash
# 1. 生成示例素材（可选）
python3 sample/generate_sample.py          # 输出到 sample/out/

# 2. 打开工具
open index.html
```

在工具中：先「导入字符映射表」选 `sample/out/mapping.json`，
再「导入字形图片」全选 `sample/out/glyphs/` 下的 PNG。

## 测试

```bash
node test/logic.test.js   # 排版/排布核心逻辑自测（DOM 桩下运行）
```

## 度量字段约定

- `advance`（前进宽度）：渲染下一个字符前笔刷前进的距离，默认等于图片宽度
- `baseline`（基线）：字形顶端到基线的距离，默认等于图片高度（底边贴基线）
- 导出 JSON 中 `yoffset = 全局基线 - 字形基线`，即行顶到字形顶端的距离（BMFont 约定）
- 排版单元宽度 = `advance + 字符间距`
