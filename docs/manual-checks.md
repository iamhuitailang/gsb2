# 手动验收清单

用 `npm start` 打开 `http://127.0.0.1:5173` 后逐条验证。每条都尽量写清
“怎么做、应该看到什么”。

## 1. 非等时长帧与时间轴

- [ ] 首屏载入「苔灯蘑菇」，底部时间轴出现 8 张卡片，标注 `#1…160ms` …
      `#5…240ms`，时长互不相同。
- [ ] 右侧预览点击「播放」：呼吸有快有慢，第 5 帧（眨眼）明显停留更久；
      「循环总长」显示 1120 ms。
- [ ] 选中第 2 帧，把「停留」改成 500，点「应用到全部」：所有卡片变为 500ms，
      循环总长变为 4000 ms。
- [ ] 撤销两次：先恢复原时长，再恢复第 2 帧的修改。
- [ ] 拖动卡片 `#7` 到 `#2` 之前：卡片顺序变化，预览顺序同步；撤销可还原。
- [ ] 点「＋ 插入」：当前帧后新增空白帧，新帧成为当前帧；「复制」得到内容相同的帧。
- [ ] 只剩 1 帧时「删除」按钮不会把最后一帧删掉（状态栏提示至少保留 1 帧）。

## 2. 绘制与缩放

- [ ] 缩放调到 1×、3×、8×、40×，分别在画布四个角点一下：
      像素落点与指针位置一致，笔尖不偏移（重点检查高 DPI 屏幕）。
- [ ] 快速拖动鼠标画长线：线条连续，没有断点。
- [ ] 笔尖设为 5px 后填充：落笔范围以指针为中心。
- [ ] 填充只填连通区域：先画一条闭合线，在闭合区域内填充，区域外不受影响。
- [ ] 切到「橡皮」拖动：像素变为透明（露出棋盘格），撤销后恢复。
- [ ] 切到「取色」或右键点击：当前颜色变为所点像素的颜色。
- [ ] 双击调色板色块打开改色对话框：
      - 不勾选「同步替换」：应用后画布像素颜色不变，调色板条目变化；
      - 撤销后勾选「同步替换」再应用：画布上该颜色的像素全部替换，状态栏显示替换数量；
      - 撤销：颜色和像素一起恢复。

## 3. 图层、洋葱皮、差异

- [ ] 点击图层眼睛图标隐藏「菌伞」：画布上菌伞消失；预览里也消失。
- [ ] 打开「导出…」，GIF 报告显示隐藏图层已被排除；导出后打开 GIF 确认没有菌伞。
- [ ] 锁定「身体」图层后绘制：无法落笔，状态栏提示图层已锁定。
- [ ] 双击图层名可重命名，`Enter` 确认、`Esc` 取消。
- [ ] 开启洋葱皮：前一帧偏红、后一帧偏蓝；把「前 / 后」改为 2–3，更远的帧更淡。
- [ ] 开启「帧间差异」：第 1 帧与最后一帧对比（循环接缝），绿/品红/黄像素高亮，
      右侧「差异像素」显示 `+新增 −移除 ~改色`。
- [ ] 洋葱皮与差异互斥：开启一个，另一个自动关闭。

## 4. 撤销 / 重做

- [ ] 一次完整拖动只算一步撤销（画完一笔按一次 Ctrl/Cmd+Z 整条笔划消失）。
- [ ] 在第 1 帧画一笔 → 切到第 4 帧画一笔 → 回到第 1 帧按撤销：
      第 1 帧最后那一笔被撤销，**第 4 帧保持不变**。
- [ ] 在第 2 帧画一笔，切到第 5 帧后按撤销：视图自动跳回第 2 帧再撤销。
- [ ] 撤销后重做：选择回到操作完成时所在的帧与图层。
- [ ] 连续插入 3 帧后连续撤销：帧数逐步回到 1，顺序与选择都正确。
- [ ] 撤销到底后按钮变为禁用；此时做新操作，重做链清空。
- [ ] 笔划进行中直接按撤销：整条未完成的笔划回滚，不留残影。

## 5. 保存与导出

- [ ] 「保存工程」下载 `*.pixanim.json`；「打开」重新导入后，
      帧数、帧时长、图层可见性、调色板、像素完全一致。
- [ ] 手工把工程 JSON 的 `width` 改成 4 再打开：提示「宽度需在 8-256 之间」，
      当前工程不被破坏。
- [ ] 导出 GIF：透明背景保留（在深色背景的应用里打开），每帧时长正确。
- [ ] 把某帧设为 125 ms，打开导出对话框：报告里用 ⚠ 标出 `125→130ms`；
      把该帧改成 120 ms 后警告消失。
- [ ] 导出精灵表（网格 4 列、间距 2、4×）：PNG 透明背景，每格图案正确，
      同时下载的 JSON 中每帧 `x/y/w/h/duration/elapsed` 正确。
- [ ] 精灵表「横向条带」与「网格」两种排版都正确。

## 6. 样例

- [ ] 顶栏「载入样例」可随时恢复 8 帧样例（会清空当前工程和历史）。
- [ ] 样例包含 4 个图层：影子（半透明）、身体、菌伞、表情，默认全部可见。
- [ ] 关闭「表情」图层后导出：GIF 中没有眼睛和嘴，其他部分正常。

## 7. 快捷键

- [ ] `B/E/G/I` 切工具，`[`/`]` 调笔尖，`+`/`-` 缩放。
- [ ] 空格播放 / 暂停预览。
- [ ] `,` / `.` 切帧，`↑` / `↓` 切图层，`Alt+←` / `Alt+→` 调整帧顺序。
- [ ] `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` 撤销重做，`Ctrl/Cmd+D` 复制帧，
      `Delete` 删除帧，`Ctrl/Cmd+S` 保存，`Ctrl/Cmd+E` 导出。
- [ ] 在输入框（工程名、停留时间）里按这些键不会触发画布操作。
