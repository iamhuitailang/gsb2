把长视频切成可查的镜头目录

导入本地视频后自动生成缩略图与候选镜头边界；调整灵敏度、合并误切、手动补切点；给片段加标签和备注，按标签 / 时长 / 时间范围筛选，最后导出可离线浏览的网页目录。

  • 视频只在本机读取，不会上传。
  • 缩略图按“片段起止 + 取样点”寻址，改边界后自动换新图，不会错位。
  • 每个切点都附带判断依据；短促但明显的切换会保留。

样片包含硬切、慢变化、静止画面、短镜头、闪光与弱变化，由本机 ffmpeg 生成。
